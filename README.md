# BunkBuddy - Smart Academic & Attendance Manager

BunkBuddy is a personal academic tracking app that helps students:
- Plan their timetable schedule
- Monitor real-time subject attendance
- Calculate precise safe bunk limits (how many lectures you can skip safely)
- Calculate exact consecutive recovery lectures required to reach target percentage
- Visualize statistics with interactive graphs & subject breakdowns
- Focus with built-in Pomodoro study timer intervals
- Store important notes securely with local IndexedDB speed

## Features
1. PIN-Based Authentication
2. Profile Management
3. Subject Tracking & Attendance Thresholds
4. Timetable Schedule & 1-Click Logging
5. Attendance Statistics & Bunk Math Engine
6. Pomodoro Productivity Timer
7. Local Notes Vault
8. Encrypted Data Export & Import Backup
9. Dual IndexedDB + LocalStorage High-Speed Engine
10. Progressive Web App (PWA) Offline Support
